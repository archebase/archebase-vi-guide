# Deck playbook

Load with the shared `pptx` skill. Keep responsibilities separate: this playbook decides brand composition; `pptx` owns OOXML and file mechanics.

1. Fill `templates/brief.md` and create slide inventory: number, purpose, one judgment, evidence, recipe, background, logo asset, open approval.
2. Classify slides as system statement, evidence-led, transformation flow, comparison, or image-led.
3. Use 16:9 unless specified; vary layouts; every slide needs meaningful evidence or structure.
4. Select current SVG logo through the resolver; use PNG only when raster output requires it.
5. Use native charts where PowerPoint supports them. Titles state conclusions; include units, time, sample and source.
6. Run the shared `pptx` content QA, validator, rendered visual QA and thumbnail grid. Fix overflow, overlap, low contrast and repetitive layouts.
7. Report technical file QA separately from brand QA. Unconfirmed logo geometry, type sizing, color ratio or naming blocks release.
