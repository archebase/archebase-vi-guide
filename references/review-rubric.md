# Review rubric

Score each dimension 0–2: judgment clarity, evidence hierarchy, asset correctness, color discipline, typography, composition, channel fit, claims/rights.

- Any 0 in judgment, asset correctness, or claims/rights → `阻塞，待确认`.
- Total below 14 → `修复后复审`.
- 14–16 is only eligible for human review, never automatic publication.

Report each issue:

```text
Severity: Blocker | Major | Minor | 待确认
Finding:
Why it matters:
Concrete fix:
Source / Guide page:
Release impact:
```

Review order: judgment → evidence → composition → Logo → color → type → image/icon/chart → export/accessibility → rights. Separate technical QA from brand QA.
