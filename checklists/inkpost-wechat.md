# InkPost / WeChat article checklist

- [ ] Brief identifies the article, primary audience judgment, target WeChat destination and preview width.
- [ ] Mode selected: `guided` by default; `strict` for formal VI sign-off.
- [ ] One `h1`; no more than three meaningful hierarchy levels.
- [ ] Conclusion appears before explanatory metadata where the narrative permits.
- [ ] Theme source named: tracked preset, local user theme or explicit import.
- [ ] CSS uses the approved primary palette and only the documented light blue article tints.
- [ ] No orange CTA/status color, arbitrary saturated color, or article-layout gradient.
- [ ] The deterministic InkPost CSS validator passes against the exact CSS to be exported.
- [ ] InkPost's own WeChat compatibility scanner has no unreviewed warning.
- [ ] Images explain evidence/narrative, retain aspect ratio and are inspected at the actual crop.
- [ ] Any Logo is a resolved, unmodified V2 asset; no generated, recolored or CSS-improvised logo.
- [ ] Claims, metrics, customer material, image rights and naming have sources or owners.
- [ ] Rendered Markdown inspected at target preview width: heading wrapping, body, callouts, code, tables and images.
