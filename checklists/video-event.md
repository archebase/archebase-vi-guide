# Video / event-screen checklist

- [ ] Mode selected in the brief; formal identity screens use strict, campaigns/events may use creative
- [ ] `templates/brief.md` filled with playback surface, native resolution and viewing distance
- [ ] Scene inventory has one judgment per scene
- [ ] Type and mark sized for worst-case viewing distance, not the best seat
- [ ] Mark and critical text inside the venue safe area; the safe-area source is recorded
- [ ] Contrast checked on the actual screen or a calibrated preview
- [ ] Mark never placed on a moving or high-detail passage
- [ ] Mark static or stable; not animated, morphed or recreated
- [ ] Motion only where it explains a claim; decorative animation removed
- [ ] Every text-bearing moment holds long enough to read at the briefed distance
- [ ] Any audio-carried claim also has a visual carrier
- [ ] Reviewed at the real surface and distance; frame-stepped over every text moment
- [ ] Crop checked on every aspect ratio in scope
