# Image checklist

- [ ] Mode selected in the brief; strict is opt-in and creative mode is appropriate for campaign/editorial imagery
- [ ] `templates/brief.md` filled with the claim the image carries and its placement
- [ ] Checked whether real physical-world evidence or an existing approved image already covers it
- [ ] No prompt requested the ArcheBase mark or any approximation of it
- [ ] No generated on-image text; real text added in the layout tool
- [ ] Prompt targets the needed composition, with a calm area for type and the mark
- [ ] Generic "AI futuristic" register avoided: no node graphs, circuit wallpaper, glow, rainbow palettes
- [ ] No recognizable real person, specific customer facility or third-party mark prompted
- [ ] Provenance recorded: model and version or library and asset ID, license, date, prompt, reviewer
- [ ] Output inspected for malformed lettering, text-like artifacts, deformed anatomy, impossible geometry
- [ ] No accidental logo, wordmark or third-party mark anywhere in the frame
- [ ] Inspected at final crop and final placement; type and mark stay legible over it
- [ ] Checked at its smallest real usage size
