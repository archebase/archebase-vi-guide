# Deck checklist

- [ ] Mode selected in the brief; use `strict` for formal external/company decks and `guided`/`creative` when the brief allows authorship or channel latitude
- [ ] `templates/brief.md` filled; slide inventory has one judgment per slide
- [ ] Relevant Guide pages inspected with a page-inspection record each
- [ ] Each slide classified: system statement, evidence-led, transformation flow, comparison, or image-led
- [ ] Logo variant resolved through the resolver and recorded; no redrawn or regenerated mark
- [ ] 16:9 unless the brief specifies otherwise; layouts vary
- [ ] Titles state conclusions; units, time, sample and source present on every metric
- [ ] Native charts used where PowerPoint supports them
- [ ] Shared `pptx` content QA, validator, rendered visual QA and thumbnail grid run
- [ ] Overflow, overlap, low contrast and repetitive layouts fixed
- [ ] Technical file QA reported separately from brand QA
